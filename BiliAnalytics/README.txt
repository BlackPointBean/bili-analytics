========================================
  BiliAnalytics - B站视频数据监控
========================================

安装位置：C:\Program Files\BiliAnalytics\
启动器：C:\Program Files\BiliAnalytics\启动面板.cmd

────────────────────────────
  使用方法
────────────────────────────


  打开 C:\Program Files\BiliAnalytics\
  双击 启动面板.cmd
  → 自动启动后台服务
  → 2秒后自动打开浏览器显示数据面板



────────────────────────────
  日常使用
────────────────────────────

• 添加视频：在页面顶部输入 BV 号 → 点击 +再等待一段时间
• 关闭浏览器 = 只是关掉页面，后台服务继续采集
• 每次想看数据：打开安装目录 → 双击 启动面板.cmd
• 如果服务已在运行，会直接打开浏览器

────────────────────────────
  注意事项
────────────────────────────

• 最多建议监控 5 个视频，避免 B站 封 IP
• 采集频率：白天 15 分钟一次，凌晨 30 分钟一次
• 数据保存在：%ProgramData%\BiliAnalytics\bili.db
